# معاهدة — إدارة أوراد القرآن (متعددة)

تطبيق ويب تقدمي (PWA) لإدارة وتتبع عدة أوراد قرآنية في نفس الوقت (مراجعة، حفظ جديد، ختمة يومية، تجويد، سند...) بشكل مستقل تمامًا لكل ورد.

## المزايا
- إدارة أوراد متعددة، كل ورد له اسم ولون وأيقونة ونطاق وأيام مستقلة.
- توزيع تلقائي (تقسيم متساوٍ) أو يدوي (كمية يومية محددة).
- طرق تحديد الورد: بالصفحة، بالربع، بالحزب، بالجزء، بالسورة، أو مختلط (صفحة + سورة) — عبر أزرار سهلة وعدّادات (+/-) بدل الكتابة اليدوية.
- تحويل تلقائي لكل الطرق إلى صفحات المصحف المدني (604 صفحة).
- الأسبوع يبدأ من يوم **السبت** في كل مكان (اختيار الأيام، العرض، الجدولة).
- اختيار أيام محددة لكل ورد (مثال: سبت-خميس، أحد-أربعاء، الجمعة فقط...).
- صفحة "اليوم" مرتبطة بالتاريخ واليوم والوقت الفعلي، مع إمكانية التنقل بين الأيام (أسبوع للخلف وأسبوع للأمام) عبر سهمي ‹ ›.
- عند تحديد المهمة "تم"، تُحذف من القائمة تلقائيًا وينتقل العرض مباشرة لليوم التالي.
- إعادة توزيع ذكية عند تفويت يوم (أو الإبقاء على الجدول الأصلي حسب اختيار المستخدم).
- أيقونات SVG أصلية بدل الإيموجي (كتاب، مسجد، هلال، نجمة، قلم، تدوير، هدف، رصّ كتب).
- قابل للتثبيت على الهاتف كتطبيق (PWA) مع عمل بدون إنترنت (Service Worker).
- تصميم عربي RTL نظيف بخط IBM Plex Sans Arabic، وحفظ البيانات محليًا (localStorage).

## النشر على GitHub Pages
1. ارفع كل الملفات إلى مستودعك (أو فرع `gh-pages`).
2. من إعدادات المستودع (Settings → Pages) اختر المصدر: الفرع الرئيسي والمجلد الجذري.
3. بعد النشر، افتح الرابط من متصفح الهاتف، ثم من قائمة المتصفح اختر "إضافة إلى الشاشة الرئيسية"، أو استخدم زر "تثبيت التطبيق" الذي يظهر تلقائيًا في المتصفحات الداعمة (Chrome/Edge على أندرويد).

## ملاحظة حول بيانات الأجزاء/الأحزاب/الأرباع
صفحات بداية السور والأجزاء مأخوذة من الترقيم المعتمد لطبعة مجمع الملك فهد (604 صفحة). أما حدود الأحزاب والأرباع داخل كل جزء فمحسوبة تقريبيًا (تقسيم متساوٍ داخل الجزء) لعدم توفر قاعدة بيانات آية-بآية في هذا الإصدار. يمكن لاحقًا استبدالها ببيانات دقيقة بالكامل (ملف `mushaf-data.js`) إن رغبت.

## الملفات
- `index.html` — الواجهة الرئيسية
- `app.js` — منطق التطبيق (الخطط، الجدولة، إعادة التوزيع، التنقل بين الأيام)
- `icons.js` — مكتبة أيقونات SVG المستخدمة في التطبيق
- `mushaf-data.js` — قاعدة بيانات صفحات المصحف
- `manifest.json` — إعدادات PWA
- `service-worker.js` — التخزين المؤقت للعمل بدون إنترنت
- `icon-192.png`, `icon-512.png` — أيقونات التطبيق (شاشة رئيسية)
